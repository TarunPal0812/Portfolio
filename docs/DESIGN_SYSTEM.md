# DESIGN_SYSTEM.md: Portfolio 2.0 (Precision Dark Engineering Edition)

> Bespoke design tokens, typography, dark shading, and layout principles crafted for an authentic, high-end developer aesthetic.

---

## 1. Aesthetic Direction

- **Philosophy:** Understated, high-contrast, dark-shaded engineering aesthetic inspired by Linear, Raycast, and Vercel.
- **Differentiators:** Zero synthetic neon text gradients or gimmicky decorative animations. Grounded, authentic technical typography, precision 1px borders, subtle dark geometric grid, and deep obsidian/charcoal surfaces.

---

## 2. Color Tokens & Dark Shading

- **Root Background:** `#090A0F` (Obsidian Charcoal)
- **Sub-Surface Panels:** `rgba(15, 17, 23, 0.7)` / `#0E1017` with subtle `rgba(255, 255, 255, 0.07)` border
- **Hover Panel State:** `rgba(20, 23, 31, 0.85)` with `rgba(255, 255, 255, 0.14)` border
- **Foreground Primary:** `#F8FAFC` (Slate 50 / Crisp White)
- **Foreground Secondary:** `#94A3B8` (Slate 400)
- **Foreground Muted:** `#64748B` (Slate 500)
- **Engineered Accent:** Muted Electric Indigo (`#6366F1` / `#818CF8`) reserved strictly for active indicators, primary call-to-actions, and technical focus rings.

---

## 3. Typography & Spacing

- **Primary Body:** `Geist`, -apple-system, sans-serif
- **Headings:** `Space Grotesk`, sans-serif (tight tracking: `-0.03em`)
- **Code & Metadata:** `JetBrains Mono`, monospace
- **Grid Layout:** 4-column / 12-column responsive layout with max width `56rem` (896px) for optimal line-length and focused readability.

---

## 4. Components

- **Navbar:** Floating dark glass pill (`#0B0D13/80` with `1px border-white/[0.08]`) with real-time 1.5px scroll progress line.
- **Hero:** Bold, crisp typography with real status indicator, direct value statement, and primary tech stack tags.
- **Projects:** Bento grid with 16:9 screenshot bezel, clear technical tagline, stack badges, and interactive case-study modal dialog.
- **Skills:** Categorized technical spec sheets with domain grouping (GenAI & Agentic AI, Backend & Systems, Frontend Engineering, DevOps & Tooling).
- **Experience:** Clean vertical chronological timeline tracking engineering milestones and CS coursework.
- **Contact:** Clean dark form inputs with direct email, phone, and location channels.
